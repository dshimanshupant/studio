# **App Name**: ModelVerse

## Core Features:

- Model Selection Dropdown: A dropdown menu to select from a list of available LLM models. The list of models will be hardcoded.
- Message History Display: Display the conversation history. Messages are shown in chronological order with clear separation between user and model responses.
- Message History Management: Keeps track of all messages (user prompts and model responses) in the current session.
- LLM Integration: Send user prompts to the selected LLM model and display the response. Includes error handling for API requests.
- Text Input Field: A simple text input field for users to enter their prompts.

## Style Guidelines:

- Primary color: Neutral white or light gray for the background.
- Secondary color: Dark gray or black for text to ensure readability.
- Accent: Teal (#008080) for the active model in the dropdown and for user message bubbles.
- Use a clear, sans-serif font for all text elements.
- Simple, outlined icons for actions like 'send' and 'clear history'.
- Clean and minimalist layout with a focus on readability and ease of use.
- Subtle transitions for displaying new messages in the history.

## Original User Request:
Create an app that has drop down for llm models and keep the historical messages
